## 🌟 Vision & Overview

**Project NEXUS** rejects the paradigm of relying solely on API wrappers around trillion-parameter legacy models. Engineered independently from scratch, NEXUS proves that high-reasoning efficiency, sovereign privacy, and real-time adaptability can be achieved through disciplined architecture and self-directed multi-agent loops.

Whether running offline, on edge devices, or powering distributed multi-agent clusters, NEXUS continuously learns when you work and rethinks when you rest.

## 💻 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
* [Node.js](https://nodejs.org/) (v18.0 or higher)
* [npm](https://www.npmjs.com/) (v9.0 or higher) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/AbhijeetER/Project-NEXUS.git
   cd Project-NEXUS/nexus-frontend/Nexus.AI-main
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   Create a `.env.local` file in the root directory:
   ```env
   VITE_CLERK_PUBLISHABLE_KEY=your_clerk_publishable_key
   VITE_CONVEX_URL=your_convex_url
   ```

4. **Launch Development Server**
   ```bash
   npm run dev
   ```
   Navigate to `http://localhost:5173` in your browser.

5. **Build for Production**
   ```bash
   npm run build
   ```
